# AI4055 Capstone Python starter

Small, synthetic, standard-library-only customer-operations code for Module 9. It provides a multi-file baseline learners can inspect and extend. It does not connect to production data or implement a real authentication system.

## Run baseline tests

From this directory:

```console
python -m unittest discover -s tests -v
```

Run the small synthetic demonstration:

```console
python demo.py
```

## Capstone materials

- `feature-request.md` — dashboard request with explicit unanswered policy questions.
- `customer_health/` — a small domain, repository, and service boundary.
- `tests/` — passing baseline behavior tests. Add tests for any new behavior.

Open the course repository root in VS Code to use workspace instructions, agents, prompts, and skills. Use only synthetic data. Resolve open policy questions with the facilitator before implementing them.
