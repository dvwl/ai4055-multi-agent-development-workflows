# Module 1 Python demo

A small ticket-service package for the AI4055 Module 1 labs. The project is intentionally local and dependency-free so learners can focus on the Copilot workflow.

## Run the tests

Requires Python 3.9 or later. Open a terminal in this directory and run:

```console
python -m unittest discover -s tests -v
```

The baseline tests cover the existing filter and sort operations. The reviewed-refactor lab asks learners to add a combined operation and focused tests.

## Workspace setup

Open the repository root, not only this demo directory, in VS Code. The example workspace custom agents and Agent Skill are stored under the root `.github/` folder.
