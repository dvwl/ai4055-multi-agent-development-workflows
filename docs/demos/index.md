# Course demos

Demo projects are organized by module and are Python-focused for this course delivery.

## Module 1 Python project

The starter project is a small, local ticket-service package. It uses only the Python standard library and includes baseline unit tests.

- [Open the demo source in the repository](https://github.com/dvwl/ai4055-multi-agent-development-workflows/tree/main/demos/module-1-python)
- [Open the custom agents](https://github.com/dvwl/ai4055-multi-agent-development-workflows/tree/main/.github/agents)
- [Open the Agent Skill](https://github.com/dvwl/ai4055-multi-agent-development-workflows/tree/main/.github/skills/python-test-workflow)

Open the repository root in VS Code to use its workspace agents and skill. Run the baseline tests from the demo directory before starting a lab.
