# Lab 2: Plan model and resource use

**Time:** 25 minutes · **Mode:** team worksheet

## Task

Use `demos/module-7-governance/usage-plan.csv`. For each scenario, record a fitting workflow, task risk, what evidence is required, and when to escalate:

1. Explain an existing unit test.
2. Plan a change that crosses an API and repository layer.
3. Change authorization or tenant-scoping behavior.
4. Investigate production telemetry (discussion only; do not access production systems).

Use the model/access policy actually available to your training cohort. If the course has no account-specific usage telemetry, mark the estimate **unknown** rather than inventing a quota, price, or premium multiplier.

## Individual exercise

Choose one task and compare a narrow, staged workflow with a broad “do everything” prompt. Estimate which work can be verified cheaply and which requires a human decision. State a stop/escalation condition.

## Deliverable

Completed worksheet plus a short explanation of how task risk, verification cost, and available entitlements affect model/workflow choice. Do not include private usage or account details in public repo changes.
