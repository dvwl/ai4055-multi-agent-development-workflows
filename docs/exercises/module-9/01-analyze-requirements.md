# Capstone Lab 1: Analyze requirements

**Time:** 25 minutes · **Mode:** team

## Task

Use `demos/capstone-python/feature-request.md` as the source. Ask Copilot to produce a structured feature analysis, but do not implement anything.

1. Attach the feature request and inspect the starter models/service/tests.
2. Produce sections for business objective, user roles, functional and non-functional requirements, data, API, security, acceptance criteria, assumptions, and open questions.
3. Trace each requirement to either an existing file, a proposed change, or missing evidence.
4. Highlight unresolved health thresholds, authorization policy, export behavior, and freshness rules. Assign each question to a human approver.
5. Peer-review the analysis for invented fields, unsupported policy, or acceptance criteria that cannot be tested.

## Deliverable

`feature-analysis.md`, a requirements traceability table, and an open-question log with an owner. Stop before implementation if any unresolved item changes authorization or tenant access.
