# Capstone Lab 2: Ground and approve the plan

**Time:** 30 minutes · **Mode:** team with technical lead

## Task

1. Review global and scoped instructions, custom agents, skills, and workflow prompts.
2. Inspect the Python starter and tests. Identify which behavior already exists and what is missing.
3. If the Module 4–6 MCP API is available, retrieve only approved synthetic schema metadata. Record the tool result and source; otherwise explicitly mark database context unavailable.
4. Ask Copilot for an architecture and dependency-aware implementation plan referencing requirements and repository paths.
5. Review the plan against role/tenant boundaries, result limits, tests, and public contracts.
6. A human lead records approval or sends it back with specific changes. Do not treat Copilot's own approval as the gate.

## Deliverable

Approved plan, dependency map, test matrix, context evidence, and a list of decisions intentionally left unresolved.
