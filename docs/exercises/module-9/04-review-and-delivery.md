# Capstone Lab 4: Review and delivery

**Time:** 20 minutes plus team presentations · **Mode:** reviewer / release approver

## Review simulation

1. Ask the reviewer agent to inspect the final diff without edits.
2. Independently check tenant filters, authorization assumptions, bounded results, errors, and test coverage.
3. Classify findings by impact, cite evidence, and record the fix or accepted limitation.
4. Generate a structural summary from changed source files, not the initial plan. Verify each component and data flow against code.
5. Draft a pull-request description with requirements, design, security, tests actually run, risks, and evidence.
6. A different authorized human makes the final approval decision. Do not merge as part of this exercise.

## Individual reflection

Each learner traces one requirement from the feature request to acceptance criteria, changed file, test, and PR summary. Identify one decision that required human judgment and one claim Copilot could not verify alone.

## Deliverables

Review findings and disposition, verified structural summary, PR draft, test evidence, and recorded human decision. The capstone is not complete if a critical security finding remains unresolved or test results are misrepresented.
