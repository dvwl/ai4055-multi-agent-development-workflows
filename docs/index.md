Course exercises and demo projects for *Implementing Multi-Agent Development Workflows with GitHub Copilot* (AI4055). This Jekyll site is the course-wide home for Modules 1–9.

## Course learning outcomes

The course is designed to help learners:

1. Design agent workflows that support software delivery.
2. Implement declarative and hosted agent workflows.
3. Integrate approved tools and APIs into agent workflows.
4. Apply governance, approval, and verification practices.
5. Design multi-agent workflows that junior staff can operate safely.

Module 1 uses a small local Python project and does not require a database, cloud service, or external credentials. Later module materials will reflect their own course topics and prerequisites.
