## Start here

1. Review the [AI4055 course outline](https://www.dreamcatcher.asia/training/4055?scroll=1).
2. Begin with [Module 1: Introduction to Copilot Multi-Agent Architecture](https://dvwl.github.io/ai4055-multi-agent-development-workflows/exercises/module-1/) and complete its labs in order.
3. Clone the [course repository](https://github.com/dvwl/ai4055-multi-agent-development-workflows) and open its root folder in VS Code so the workspace agents, instructions, prompts, and skills are available.
4. Start with VS Code, GitHub Copilot Agent Mode, and Python 3.9+. Module 1 uses a local Python demo; it needs no database or cloud service.
5. Run the baseline tests from `demos/module-1-python/` before beginning the implementation lab:

   ```console
   python -m unittest discover -s tests -v
   ```

Modules 4–6 have additional Python and optional local MySQL setup instructions in their demo README. Use synthetic data only.
